Grab any page.
Hand it to your AI.

SourceGrab captures a web page's full source — rendered DOM with open shadow roots, original HTML and headers, scripts, styles, frames, globals and storage keys — plus a page map, and bundles it into one paste for ChatGPT, Claude or Gemini.

What it does

01 // SCANFull page grab

The whole rendered page in one go, with a page-map summary of components, forms and stable selectors.

02 // TARGETOne element

Target-lock picker or right-click "grab this element" to pull just the part you care about.

03 // CLEANRemove rubbish

Drops libraries, framework runtime, trackers and duplicates and shows the tokens it saved. Undo any time.

04 // SAVEOffline .html

Save the page as one self-contained file, with minor Base64 / atob() obfuscation decoded.

05 // GUARDRedact secrets

Masks tokens, JWTs, API keys and session values before anything is copied.

06 // HUDYour way

Drag and resize from any edge. Seven themes including Mono and Paper, and a 17-language interface.

Install

Load it in Chrome

  1. Download SourceGrab v3.2.4 below and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder (the one with manifest.json).
  4. Pin the SourceGrab icon, open any normal page and click it. The HUD appears.

Privacy policy

EFFECTIVE 30 OCTOBER 2026 · APPLIES TO SOURCEGRAB v3.0 AND LATER AND TO THIS WEBSITE

SourceGrab has no servers and no accounts. It does not collect, sell or share any data about you or the pages you visit.

What it reads

Only when you press scan or grab an element, SourceGrab reads the page in your current tab: its HTML, scripts, styles, frames, page variables, storage keys and the list of resources it loaded. To bundle the page it may re-download the page's own files from the same addresses the page already used.

Where it goes

Nowhere. The bundle stays in your browser until you copy it or save it as a file. If you paste it into an AI service, that service's own privacy policy applies to what you paste.

What it stores

ItemWhere
Settings (theme, language, capture options)The browser's local storage, on your computer
HUD position and sizeThe browser's local storage, on your computer
Captured pagesNot stored. Gone when you close the HUD or the tab

Secrets

"Redact secrets" is on by default and masks tokens, JWTs, API keys and session values in the bundle. Check the output before you share it anyway.
