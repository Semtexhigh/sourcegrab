Capabilities

Everything in one paste

Rendered DOM incl. open shadow roots, original HTML + headers, inline & external scripts, templates, CSS, same-origin iframes, globals, storage keys, the network list — plus a page-map summary.

Remove rubbish

Drop libraries, framework runtime, trackers, duplicates and empty files in one click — and see how many tokens that saves.

Grab one element

Target-lock picker, or right-click any element → "SourceGrab: grab this element".

Save offline .html

Export the page as one self-contained file you can double-click, with minor Base64/atob() obfuscation decoded.

Holographic HUD

Draggable, resizable panel. 7 colour themes incl. mono & light, and a 17-language interface.

Nothing phones home

No analytics, no remote code, no network calls of its own. System fonts only.

Deploy
  1. Download and unzip the SourceGrab package.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the folder with manifest.json.
  4. Pin the icon, open any page and click it — the HUD boots.
