SourceGrab / page source, bundled for an AI

A Chrome (MV3) extension that captures a web page’s full source — rendered DOM including open shadow roots, original HTML and response headers, inline and external scripts, templates, CSS, same-origin iframes, page globals, storage keys and the network list — plus a page-map summary, and bundles it all for pasting into an AI. It runs as a floating holographic HUD on top of the page.

Home History Showcase

INSTALL — LOAD UNPACKED

  1. Open chrome://extensions.
  2. Turn on Developer mode (top-right).
  3. Click Load unpacked and choose the SourceGrab folder (the one with manifest.json).
  4. Pin the SourceGrab icon, open any normal page, and click it — the HUD appears.

WHAT IT DOES

  • Grabs the whole rendered page and bundles it for an AI, with a page-map summary.
  • Remove rubbish drops libraries, framework runtime, trackers and duplicates — and shows the tokens saved.
  • Target-lock picker and right-click “grab this element” pull a single element.
  • Save page .html writes one self-contained offline file, with minor Base64/atob() obfuscation decoded.
  • 7 colour themes (incl. mono + light) and a 17-language UI. No network calls; nothing leaves the browser.
Build history & source (password)

Every build and its source is encrypted on the History page. The password derives the key — a wrong one simply opens nothing.
